# Security Policy

## Supported versions

| Version | Supported |
|---|---|
| 0.1.x | ✅ |

## Reporting a vulnerability

Please **do not** open a public issue. Report vulnerabilities privately through
[GitHub Security Advisories](https://github.com/maeandrew/laravel-ua-banks/security/advisories/new).

You will get a response within 7 days. Once a fix is released, the advisory will be published with credit
to the reporter, unless you prefer to stay anonymous.

Bank data comes from the National Bank of Ukraine. Inaccurate registry data is not a security issue
in this package.
